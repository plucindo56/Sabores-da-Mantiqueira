# Sabores da Mantiqueira

Site estático para GitHub Pages, com catálogo, filtros, carrinho e pedido por WhatsApp.

## Publicação gratuita no GitHub Pages

1. Crie uma conta no GitHub em https://github.com/ se ainda não tiver.
2. Crie um novo repositório, por exemplo: `sabores-da-mantiqueira`.
3. Envie todos os arquivos desta pasta para o repositório.
4. No GitHub, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`.
7. Salve. O GitHub fornecerá o endereço do site.

## Antes de publicar

Abra `config.js` e substitua:
`5511999999999`

pelo WhatsApp real da loja, no formato internacional, sem `+`, espaços ou parênteses.

## Produtos

Os produtos estão no começo do arquivo `script.js`. Você pode alterar:
- nome;
- categoria;
- produtor;
- preço;
- unidade;
- emoji/imagem.

Para colocar preço real, altere `price:0` para, por exemplo, `price:89.90`.

## Importante

O site está preparado para catálogo e pedidos. Para vender alimentos pela internet de forma profissional, confirme as exigências fiscais, sanitárias, de rotulagem, conservação e transporte aplicáveis aos produtos e à sua operação.

GitHub Pages hospeda os arquivos do site; domínio próprio e recursos de pagamento/checkout são etapas separadas.

O catálogo foi estruturado com referências a produtores/produtos encontrados em fontes públicas da Mantiqueira. Antes de publicar preços, fotos, marcas ou afirmar disponibilidade, confirme autorização comercial diretamente com cada fornecedor.
